# Speculative Taint Tracking (STT) in gem5

## Overview

This project evaluates **Speculative Taint Tracking (STT)** using the gem5 simulator. We compare different configurations, including a baseline and STT-enabled models. Some SPEC CPU2017 benchmarks were used to analyze performance impact.

## Project Structure
```text
.
├── configs/             # Modified gem5 configs
├── scripts/             # Build, run, and plotting scripts
├── runs/                # Simulation outputs (not included in repo)
├── plots/               # Generated figures
├── spec2017/            # Local SPEC CPU2017 (user-provided)
└── (other project files)
```

## System Requirements
* Linux-based system
* gem5 (X86 build)
* SPEC CPU2017 (user must provide their own copy)
* Python 3 (for plotting)

## Build gem5 (X86)

```bash
scons build/X86/gem5.opt -j16
```

## Benchmark Setup (SPEC CPU2017)

This project uses SPEC CPU2017 benchmarks.

A local copy is used in this project directory. Users must have their own SPEC CPU2017 to reproduce the results.

### Setup Steps
1. Place SPEC2017 under the project directory:

```
./spec2017
```

2. Prepare configuration file:

```bash
cp Example-gcc-linux-x86.cfg gcc-linux-x86.cfh
```

3. Modify the configuration file as needed (e.g., gcc path)


## Benchmarks Used

The following SPEC CPU2017 benchmarks are used in this project:
* 505.mcf_r
* 519.lbm_r
* 531.deepsjeng_r
* 557.xz_r

## Build Benchmarks

Run:

```bash
./scripts/build_benchmark.sh
```

## Run Simulation

Run:

```bash
./scripts/run_benchmark.sh
```

* Simulations are executed for multipled configurations (baseline and STT variants)
* Outputs are stored in :
```
runs/
```

* Estimated runtime: ~50 minutes on a single-core setup with a 15M instruction limit

## Execution Details

* gem5 is executed in **System Emulation (SE) mode** using the `DerivO3CPU` model
* Single-core configuration (`--num-cpus=1`) is used for all experiments
* Memory is set to 4GB with L1 and L2 caches enabled
* Each benchmark runs with a fixed instruction limit (`-I`)
* Benchmark binaries are passed using `-c`, with optional input via `-o`
* STT-related configuration flags:
    - `--STT`: enables or disables STT
    - `--implicit_channel`: controls implicit channel tracking
    - `--explicit_channel`: controls explicit channel tracking
    - `--futuristic_model`: enables the advanced STT model
* Simulation outputs are redirected to log files and statistics are stored in `stats.txt`

## Results and Metrics

Simulation results are ollected from `stats.txt` files generated by gem5.

Key metrics:
* IPC (Instructions Per Cycle)
* Number of cycles
* Normalized execution time (relative to baseline)
